# 📊 Customer Churn Data Cleaning & Structural Validation

A professional data-cleaning project using **Python and Pandas** to transform raw customer churn data into a clean, consistent, and analysis-ready dataset.

## 🎯 Project Objective

The objective of this project is to clean and validate a customer churn dataset by:

- 🔍 Inspecting the dataset structure
- 🧹 Handling missing values
- 🔁 Detecting duplicate records
- 📋 Standardizing column names
- ✨ Cleaning categorical values
- 🔢 Validating data types
- 🛡️ Performing structural validation
- 💾 Exporting the cleaned dataset

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 📓 Jupyter Notebook
- 📄 CSV
- 📊 Excel

## 🔎 Data Cleaning Process

### 1. Dataset Inspection

The raw dataset was inspected for:

- Number of rows and columns
- Data types
- Missing values
- Duplicate records
- Categorical variables
- Numeric variables

### 2. Missing Value Analysis

Missing values were checked across all columns.

**Result:** ✅ No missing values were found in the supplied dataset.

### 3. Duplicate Detection

The dataset was checked for duplicate records.

**Result:** ✅ No duplicate records were found.

### 4. Column Standardization

Column names were standardized using lowercase `snake_case`.

### 5. Categorical Data Cleaning

Categorical values were cleaned by removing unnecessary leading and trailing spaces.

### 6. Numeric Data Validation

Numeric fields were validated to ensure appropriate numeric values and valid ranges.

## 🛡️ Structural Validation

| Validation Check | Status |
|---|---|
